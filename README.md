# Audio Equalizer Using Python

### A GUI-Based Audio Processing and Equalization Application

A Python-based audio processing project developed to provide an interface for uploading audio files and applying equalization.

---

## 📌 Project Overview

The Audio Equalizer is a software development project created as part of the Signals and Systems course.

The application provides a graphical user interface through which users can upload audio files and process them using equalization features.

The project combines programming and signal processing concepts to demonstrate practical applications of audio processing.

## 🎯 Objectives

- Develop a graphical audio equalizer application.
- Enable users to upload audio files for processing.
- Implement audio equalization according to project requirements.
- Apply concepts from Signals and Systems.
- Develop an accessible interface for audio processing.

| Technology | Application |

## 🖥️ Application Features

- Graphical user interface.
- Audio file upload functionality.
- Audio processing and equalization.
- User interaction through the application interface.

## 🔬 Working Principle

The application follows a basic audio processing workflow:

1. The user opens the application.
2. An audio file is uploaded.
3. The application processes the audio.
4. Equalization features are applied according to the implementation.
5. The processed audio is made available through the application.
